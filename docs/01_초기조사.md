## 대사 = `ETC/MSGDT.BIN` (209,340 B)
- **u16 BE 글자 번호** 인코딩(평문 SJIS 대사는 디스크 어디에도 없음). 0x8000 이상 = 제어: 800A 줄바꿈(8,392), 8025·8073·8038·802D·8064 등, **FFFF = 메시지 끝**.
- 메시지 **2,050개**(0‥0x2D196), 글자 81,648자, 쓰인 글자 **1,198종**, 번호 최대 0x4E7(→ 글꼴 ≥ 1,256칸). 0x2D198 뒤 = 0 과 RAM 주소 찌꺼기(0x002F3FD8 …) — 위치표 아님.
- 첫 메시지 = 글자판 시험(0000‥00DF 를 16개씩 800A 로 줄바꿈) → 글꼴 번호 순서 확인용.
- **메시지 위치표 없음**(실행 파일·다른 파일에서 시작 위치 목록 u16/u32 BE/LE 모두 없음) → 번호로 세어 부르는 것으로 추정(⏳PoC 로 확정 — 확정되면 길이 자유).
